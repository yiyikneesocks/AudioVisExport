## ✅ 已完成（本轮，AI 归档）

- [x] **BUG1｜蒙版图片"自己动"** —— 根因：图片几何此前由**每帧电平算出的 silhouette bbox** 决定（有电平的柱范围随音乐变）。
      修复：几何改由**独立、与电平无关的 `VisTransform`** 决定，默认 `set=false` = 铺满固定"频谱画框"（canvas 区）；
      电平只经 base alpha 决定"露多少"，绝不动图片本身。
      验证：仅低频 clip vs 宽带 clip，两帧共同可见像素 9798、结构差异 **0**（图片纹丝不动）。
- [x] **BUG2｜蒙版图片不好拉伸 / 无独立缩放 / 不吸附** —— `Edit image position` 模式把图片当可独立操作元素，复用现成手柄：
      **角=等比缩放、上下左右边=单轴拉伸、body=平移、顶圆=旋转**；几何在 base 空间、外层再套频谱变换，
      所以**频谱拉伸带动整体**、图片又可独立调；移动时**吸附到频谱画框的边/中线**；点频谱框外自动退出编辑。
- 关联：`MaskImageLayer` 的 `offsetX/Y/scale` → `VisTransform transform`；JSON/CLI 改 `mask.{scaleX,scaleY,posX,posY,centerX,centerY,rotationDeg,reset}`；
  `SpectrumMask::compose` 增 `frameRect` 形参走 transform 路径；`VisPipeline` 与 `SpectrumCanvas` 同步；§8.5.1 参数表更新。
- 构建：Linux + Windows GUI 均 0 error，已部署（21:41）；`vis_anchor_test` 28/28；无蒙版 6 样式回归全 OK；`mask.transform` 生效已测。
