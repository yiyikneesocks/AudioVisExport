- **短期**：预览降频（8fps 重算描边色 + 指数插值平滑，已实现 PreviewPaletteCache）
- **中短期**：
  - [ ] 预览分辨率解耦：预览按视口尺寸渲染，导出时全分辨率
  - [ ] 脏区/增量更新：电平未变的列不重算描边色
  - [ ] 复用 base/out 图像 buffer（避免每帧分配）
  - [ ] timer 分级：30Hz 推进音频/同步；重绘用更低帧率 + `repaint(rect)` 局部刷新
- [ ] **预渲染/看前**：outlineLookaheadFrames 默认关闭，有需求再开

## 2. 多选系统（Ctrl+A / Ctrl+点击 / 批量操作）

### 数据模型
- `SpectrumCanvas::selectedSet` (std::vector<int>)：选中集合，-1=频谱，>=0=图片索引
- `selectedImage` 保留为锚点/主选中
- `bool isMultiSelection() const { return selectedSet.size() > 1; }`

### 交互设计
- **Ctrl+A**：全选（频谱+所有图片），anchor=selectedImage 取最后一个
- **Ctrl+点击**：切换某层选中状态，锚点移至点击项
- **Shift+点击**：范围选择（首尾）
- **Esc**：清空选择
- **Delete/Backspace**：删除所有选中（频谱不可删，仅清空图片）
- **Esc**：清空选择

### 多选时行为
- **拖拽**：整体平移（各元素 transform.posX/posY 同步增量）
- **隐藏手柄**：多选时只显示移动框，隐藏旋转/缩放手柄
- **删除**：`removeSelectedLayers()` 遍历删除，撤销栈压入一次快照
- **禁用**：多选时隐藏旋转/拉伸手柄，仅显示移动框

## 4. 渲染优化（实时预览性能）

### 核心瓶颈
- `compose` 每帧：base 分配 → image 绘制 → alpha 蒙版裁剪 → 4 向滑窗最小值 → 描边混合
- 1280×720 下：~92 万像素 × 7~8 遍 ≈ 600-700M 像素操作/帧

### 优化策略（按收益排序）
| 优化项 | 收益 | 复杂度 | 优先级 |
|----------|------|--------|--------|
| 预览分辨率解耦（预览低分辨率，导出全分辨率） | ⭐⭐⭐⭐⭐ | 中 | P0 |
| 脏区/增量更新（仅变化列重算描边色） | ⭐⭐⭐⭐ | 中 | P0 |
| `base`/`out` 图像 buffer 复用（thread_local 静态） | ⭐⭐⭐ | 低 | P0 |
| 预览帧率解耦（预览 20fps / 导出 30fps） | ⭐⭐⭐ | 中 | P1 |
| 脏区/增量更新 | ⭐⭐⭐ | 高 | P1 |
| 预览帧率解耦（预览 20fps / 导出 30fps） | ⭐⭐⭐ | 中 | P1 |
| 脏区/增量更新 | ⭐⭐⭐⭐ | 高 | P1 |

### 实施路线图
1. **v0.5.6-rc1**：预览分辨率解耦 + 图像 buffer 复用 + 预览 20fps / 导出 30fps
3. **v0.5.7**：脏区增量更新 + 预览帧率解耦（预览 20fps / 导出 30fps）

## 5. 撤销系统重设计（解禁 Ctrl+Z 前置条件）
- **现状**：快照全量 JSON（params.toJson），仅结构操作压栈，滑块不快照
- **问题**：双快照、参数混合、撤销后面板不同步
- **重构方案**：
  - 命令模式：每个用户动作 = 一个可逆命令
  - 快照仅在“结构性操作”压栈：增删层、变换开始、蒙版替换
  - 滑块/颜色调整：合并为一次快照（防抖 700ms）
  - 撤销栈上限 30，支持 Redo（Ctrl+Shift+Z）
