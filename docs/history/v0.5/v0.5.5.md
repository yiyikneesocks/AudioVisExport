### 1. 频谱蒙版描边（边框）系统重构
- **三边独立**：上 / 左 / 右各"开关 + 厚度 + 透明度"（底部边框删除，无意义）；线家族（y2k/polyline/crystal/line-only）经 `sideEdgesAllowed=false` 禁左右侧边，整条只走上边框。
- **UI 改为开关组**（替代原四选一ropdown）：总开关 → 实时变色(realtime) → 逐柱变色(perBar) 层级互斥置灰；固定色（Border colour / Use average）与性能项（fps/平滑）按模式互斥。
- **perBar 颜色修复**：根因是 GUI 存驼峰 `perBar` 而核心比较小写 `perbar` 的 token 不一致 → `makeStrokePlan` 里 `toLowerCase()` 归一 + 下拉存小写 + 回填大小写无关，杜绝"所有柱一个色"。
- **实时平均色**：uniform / perBar / perFrame 按可见区取色；`PreviewPaletteCache` 预览节流 + 指数插值（导出逐帧真算，保精确）。
- **描边算法演进（关键，多轮）**：
  1. 顶缘由逐像素竖直窗 → **矢量 `strokePath`**（居中·恒定法向宽·JUCE AA·圆角连接），与 line 模式同法，消除斜线锯齿；
  2. 修 **Windows 顶缘完全不显示**：同一 Image 上 `BitmapData` 写锁未释放就建 `Graphics`（Linux 容忍、MSVC 静默不画）→ 用 `{}` 限定 `bd` 作用域；
  3. **peak caps 与描边彻底解耦**：帽画进 `base` alpha 且比柱体更宽，会同时污染"柱顶"与"左右侧边"。`compose` 拆成**裁剪轮廓(mA=含帽 base)** 与**描边轮廓(mS=无帽主体 strokeBase)**：穿透模式帽区透出图片但不描边；边框样式模式由 capOverlay 把帽像素重涂成"该柱边框颜色"（`colColour[x]`/uniform），厚度仍独立。
  4. **bar 家族顶缘回归向内带**：顶用正上方窗最小值(向内)、与左右水平窗同一形态学族 → 三边向内闭合、直角转角、无圆帽外伸（修复"顶线伸到左右下面 + 顶/侧断开"）。line 家族仍居中 strokePath。
- **阴影暂时禁用**：`shT/shL/shR=0`（原式注释保留），面板三条 shadow 滑块同步置灰（`avxBorderShadowEnabled=false`）。
- **法向等宽**：顶缘描边厚度沿曲线切线的垂直(法向)方向测量，斜面不再变细。

### 2. peak cap 外观（全局样式参数）
- `peakCapWidth`（面板 "Peak cap thickness"，**独立于边框宽度**）：bar/bar-line 帽线粗细；y2k/polyline/crystal 峰线粗细=点线里的点直径，**gap 随直径自动放大 → 点永不粘连**。
- `peakLineDotted`：线家族峰线 点线 ↔ 完整平滑曲线。
- `peakCapAsBorder`：有描边时 帽=该柱边框色(穿透 vs 边框样式，见 §1.3)。
- 全样式帽/峰线粗细统一走 `rp.peakCapWidth`；`barParticles` 仍只 gate 帽本体，主体轮廓不受影响。

### 3. 画布 ↔ 图层列表 双向多选
- 画布：`Ctrl/⌘+A` 全选、`Ctrl/⌘+点击` 增删选、多选**只整体移动**（禁一起旋转/拉伸、无手柄）、批量删除。
- 修 **全选后拖不动整组**：`mouseDown` 普通按下无条件 `selectedSet={picked}` 把刚多选塌陷 → 改为"点中已在集合内的元素则保留集合"。
- 图层列表：`setMultipleSelectionEnabled(true)`，`refreshLayerList(const std::vector<int>&)` 按整个选择集高亮多行；列表 `Ctrl/Shift` 多选回传画布同一 `selectedSet`；列表内 Delete 批量删图片行。
- `canvas.setSelection(tags, anchor)`（过滤越界/频谱不在场，锚点入集合）；画布与列表共用一套集合、双向一致。
- 顺带修 `addSpectrumLayer` 双快照 bug；`Ctrl+Z` 暂时禁用（`avxEnableUndo=false`），命令式撤销 + `Ctrl+C/V` 复制粘贴入 `docs/ROADMAP.md` 长期计划。

### 4. 默认值文件 config.json（INBOX task2）
- 位置 = exe 同目录 `config.json`。语义（用户三决策）：**启动自动加载**为初值；**稀疏覆盖、不自动回写**（缺字段吃内置默认，新增参数零维护，文件缺失/空/解析失败静默用内置默认）；面板 "Set as startup default" 按钮写**全量当前值**快照。
- 实现 `SpectrumParams::{defaultConfigFile,defaultConfigExists,loadFromDefaultConfig,saveToDefaultConfig}`，复用 `fromJson/toJson`；`vis_mask_test` 用例 15 往返校验 + 自动清理。
