### 2026-09-09 · 蒙版图片随电平漂移（BUG1）+ 不能独立拉伸（BUG2）
- 备份原话：
  1. 图片会自己移动：有一半频谱没电平时图片只平铺到有电平那侧，有电平后又放大铺满全部频段；要图片不动。
  2. 内部图片的拖放操作有问题、不好拉伸：拉不了边框、不吸附到频谱框边；要"频谱拉伸影响整体 + 图片另要有独立拉伸"。
- 方案：
  - BUG1：图片几何改由**独立、与电平无关的 `VisTransform`**（`MaskImageLayer.transform`）决定，`set=false`=铺满固定"频谱画框"；电平只经 `base` alpha 做 clip。验证：低/宽带两 clip 共同可见像素 9798、结构差异 **0**。
  - BUG2：`Edit image position` 把图片当独立元素，复用现成手柄/锚定/吸附机制（角=缩放、边=单轴拉伸、body=平移、顶=旋转）；几何在 base 空间、外层套 `p.transform`，故频谱拉伸带动整体、图片可独立调；移动吸附到频谱画框边/中线；点频谱框外退出。
  - 连动：`offsetX/Y/scale`→`VisTransform`；JSON/CLI `mask.*`；`SpectrumMask::compose` 加 `frameRect`；`VisPipeline`+`SpectrumCanvas` 同步；§8.5.1 参数表更新。
- 构建/提交：Linux+Windows GUI 0 error；`vis_anchor_test` 28/28；无蒙版 6 样式回归全过；Windows 部署 21:41；本地 commit `7546204`（未推）。
